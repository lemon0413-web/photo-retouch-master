# 摄影光影精修 · photo-retouch-master

面向 Codex 的摄影后期技能：结合原图的光线、地形与材质，通过局部明暗、选择性对比和色彩主次塑造摄影感。适用于风景、建筑、园林、海岸及自然人像精修。

## 核心方法

- 先确定视觉重心与受光/背光关系，再设计局部提亮、压暗和颜色。
- 分区处理灰雾与影调，保留中间调和远景空气感。
- 工具支持时组合区域、亮度与颜色蒙版，检查过渡、光晕和溢色。
- 保留原片，记录真实操作，检查同尺寸修前修后。
- 根据照片选择冷暖与强度，不固定套用蓝天、黄绿或全图压暗配方。

## 安装

下载并解压本仓库根目录的安装包，将其中的 `photo-retouch-master` 文件夹放入 `$CODEX_HOME/skills/`；未设置该变量时通常为 `~/.codex/skills/`。已有同名技能时先备份再替换。

仓库根目录中的 `photo-retouch-master-v1.0.0.zip` 为独立安装包，解压后得到同名技能文件夹。安装包只包含技能和参考文件。

## 使用

提供原图，然后输入：

> 使用 $photo-retouch-master 精修这张照片，通过局部光影和对比塑造大片摄影感，保留原有景物与构图。

也可以指定“自然纪实”“冷峻海岸”“突出雪坡与暖色草场”等方向。参考图用于理解审美，不自动授权改动场景或复制配色。

## 执行依赖与限制

这是决策与工作流技能，不是图像处理引擎，不捆绑 Lightroom、Photoshop、插件、模型或 API 密钥。实际操作取决于运行环境中的可用工具，始终服从该环境的工具规则。

保真路线优先使用原生摄影调整与实际蒙版；接口不支持的参数不能虚构。若使用生成式图像编辑，可能改变文字、纹理、物体细节、光照或输出尺寸，必须披露，不能宣称原像素不变或恢复真实缺失细节。没有真实蒙版产物时不能声称完成蒙版操作。

已完成技能结构与引用路径校验，并用多种照片做过生成式风格试修；尚未验证自动化非生成式精修或逐像素保真能力。风格效果不构成专业认证或质量保证。
